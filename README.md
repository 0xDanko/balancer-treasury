# Balancer Treasury Dashboard

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://0xdanko.github.io/balancer-treasury/)

A lightweight, front-end dashboard built to track and visualize the Balancer Protocol's Treasury data, highlighting the token price v. NAV (Net Asset Value). 

This project was entirely "vibe coded" using Opus 4.6, demonstrating how rapidly complex UI and data visualization concepts can be prototyped into a single, functional `.html` file.

## 🚀 Live Demo
**View the live dashboard here:** [balancer-treasury](https://0xdanko.github.io/balancer-treasury/)

## 🛠 Tech Stack
* **HTML/CSS/JS:** Single-file architecture for ultimate simplicity and easy deployment.
* **AI Assistance:** Developed and iteratively refined using Opus 4.6.
* **Hosting:** GitHub Pages.
